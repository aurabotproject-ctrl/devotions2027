# Morninglight 2027 — Build Recipe

**Working title:** Morninglight 2027 — Daily Devotions (Upper Primary)
**Purpose of this file:** the single source of truth for building the new devotion app. Read it top to bottom before writing any code or content. If a later instruction conflicts with this file, this file wins unless the teacher says otherwise. Anything marked **[CONFIRM]** is a default I have assumed; change it here before the build starts.

---

## 0. The one-paragraph brief

A **static, offline, double-click-to-open** web app (`index.html`, works over `file://`, no server, no CDN, no framework) for a teacher to run a daily devotion with an upper-primary class. **4 terms × 10 weeks × 4 days (Mon–Thu) = 160 lessons.** Every lesson is a **full-screen animated slideshow** the teacher clicks through with the class: it tells the story, asks searching questions, includes a real application, and ends with a **directed prayer** that teaches students *how* to pray. **Every Monday and Wednesday includes a role-play** (the on-screen line-by-line script presenter the students already love). **Every lesson runs 15–20 minutes.** The look is a **cinematic black-and-white manga / graphic-novel experience** matching the reference comic page (Herod's soldiers), with images generated by the teacher in ChatGPT from prompts this project supplies.

## 1. What changes from the current app

| Area | Current app | New app |
|---|---|---|
| Lesson length | 10–15 min, some days thin | **15–20 min, every day**, enforced by a validator (§14) |
| Format | Scrolling page of blocks | **Slideshow presenter** (16:9, keyboard/click/tap) + teacher notes |
| Role-play | Some weeks only | **Every Mon + Wed (80 scripts)**, same fullscreen presenter, upgraded |
| Prayer | A text block | **Directed prayer** with guided phases, prompts, silence timer, and a prayer-skill taught each week |
| Design | Flat, off-white, hairline borders | Dark cinematic stage, comic caption boxes, motion, particles, per-term colour |
| Images | Comic panels scraped from a publisher's PowerPoint, base64 in JS | **Original AI-generated art** from our prompts, plain files in `/images`, graceful placeholders when missing |
| Content source | Published curriculum books | **Original content** built from the Bible passages in §4 |
| Lesson plan | Hand-written per day | **Generated from the slides + notes** (no double-authoring), printable |

**Carry over (do not lose):** offline `file://` operation; Teacher view toggle with hints; fullscreen role-play presenter (Next/Back, arrow keys, space, tap, auto-colour per character); lesson-plan popup; read-along pacing highlighter (optional port); "every block must connect to that day's Bible content — no generic icebreakers" rule; NZ English spelling.

## 2. Decisions & assumptions **[CONFIRM]**

1. **Audience:** upper primary, roughly ages 9–12. Reading level ≈ Year 5–6; vocabulary explained, never dumbed down.
2. **Schedule:** Mon–Thu, no Friday. Terms are labelled **Term 1–4**; the cycle tags (A1/A2) are shown in the data as `cycle`. 2027 school year (NZ).
3. **Bible version:** **CEV**, as in the current app. Scripture is quoted only from text that can be verified (existing data files or a web check at build time); otherwise paraphrase and label it "paraphrase". Long passages are *told*, not pasted — scripture slides carry 1–4 verses.
4. **Theological stance:** mainstream evangelical / Protestant, Christ-centred. Hard topics (the Fall, the flood, Stephen, Polycarp) are handled honestly but gently; **no gore**, always ending in hope.
5. **Name/brand:** keep "Morninglight". Sky-blue + honey-gold from the old brand survive as accents.
6. **Depicting Jesus and God:** God the Father is **never drawn as a figure** — only light, rays, clouds, a voice. Jesus **is** drawn, reverently, with one locked character design (§13), often from behind, in silhouette, or in a wide shot. **[CONFIRM — easy to change to "never show Jesus's face"]**
7. **Real people:** historical figures (Polycarp, Tyndale, Marsden, Ruatara) may be dramatised; invented dialogue is marked on the script card as "based on historical sources; some words imagined" and documented quotes are used where they exist. **No invented words for living people.**
8. **Class names:** the teacher can type a class list once (stored in the browser only) to power a "pick volunteers" spinner for role-plays. Names never leave the device.
9. **Sound:** off by default. Optional soft UI sounds synthesised with WebAudio (no audio files).

```
│  ├─ menus.js                # home → term → week → day screens

├─ data/
│  ├─ meta.js                 # terms, colours, prayer-skill ladder, master image style block

│  ├─ shared/                 # term covers, prayer/verse/question backdrops
│  ├─ t1/w01/ … t4/w10/       # t1w01d1-a.webp, t1w01d1-b.webp, t1w01-cover.webp, t1w01-comic.webp …
│  └─ characters/             # reference sheets
├─ tools/
│  ├─ validate.js             # schema + timing + coverage checks (§14)
│  ├─ export-prompts.js       # writes IMAGE_PROMPTS_T1.md … from the data files
│  ├─ optimize-images.py      # PNG/JPG from ChatGPT → WebP, resized, right filenames
│  ├─ make-fonts.js           # pulls @fontsource woff2 via npm → css/fonts.css
│  ├─ panel-marker.html       # (Phase 5) drag rectangles on a comic page → JSON
│  └─ bundle-single-file.js   # (optional) inline images as base64 for a one-file share
├─ BUILD_STATUS.md            # what is built / validated (regenerated by validate.js)
└─ README.md                  # teacher quick-start (one page)
```

**Hard constraints**
- No `fetch()` of local files (blocked on `file://`). Data loads via `<script src>` that assign to `window.*`.
- No external network requests at runtime. Fonts are embedded. No analytics.
- Vanilla JS (ES2019), no bundler, no build step needed to *run* it. Tools in `/tools` are for building only.
- Must run in current Chrome, Edge, Safari (incl. iPad), Firefox, and on a school Chromebook at 1080p.
- Images referenced by relative path. A missing image **never** breaks a slide (see placeholder rule, §13.7).

## 4. Curriculum map (the 40 weeks)

Verses are **references only** here; exact CEV wording is verified when each week is built. 🎭 = role-play day (a different scene each time; script presenter). Each week also has a **prayer focus** (see §10) and ends Thursday with a **challenge** that Monday's check-in follows up.

> **Spine for the year:** T1 *Who is God?* → T2 *Can I trust him?* → T3 *What does Jesus teach about life with God?* → T4 *What does it look like to follow Jesus for real?*

### TERM 1 — Knowing God our Creator *(Genesis → Luke)* · cycle A1
Each week answers: **"What is God like?"** The term arc runs creation → fall → promise → rescue → king → prophets → Jesus born.

**T1 W1 — In the Beginning** · Gen 1:1–2:3, 2:15–25; Ps 19:1 · Verse: Gen 1:1
*Big idea:* God made everything by his word, it was good, and he made people to know him.
- Mon 🎭 "Let there be…" — Days 1–3; students are light, sky, land, sea in a creation chorus
- Tue — Days 4–6; sun, moon, stars, creatures; people made in God's image (1:26–27)
- Wed 🎭 The Garden — Adam names the animals; "not good to be alone"; Eve (2:15–25)
- Thu — Day 7 rest; Psalm 19 "the heavens tell"; response: wonder + thankfulness; challenge: notice and thank God for 3 made things

**T1 W2 — Broken Friendship** · Gen 3 · Verse: 1 John 1:9
*Big idea:* Sin breaks our friendship with God, but God comes looking and promises a rescuer.
- Mon 🎭 The serpent's question — "Did God really say…?" (Narrator, Serpent, Eve, Adam)
- Tue — Hiding and "Where are you?" (3:8–13); what sin is, in kid terms; gentle on consequences
- Wed 🎭 God walks in the garden — the conversation; God's voice only as text/light
- Thu — The promise of a rescuer (3:15) and God's clothing (3:21); saying sorry and being forgiven

**T1 W3 — Rescue in the Storm** · Gen 6:9–9:17 · Verse: Gen 9:13
*Big idea:* God is holy and fair, yet he saves those who trust him — and keeps his promises.
- Mon 🎭 Noah hears God — Noah, Mrs Noah, mocking neighbours chorus, God's voice
- Tue — Building; animals come; "the LORD shut him in" (7:16)
- Wed 🎭 Dove and olive leaf — Noah, Shem, raven, dove, narrator
- Thu — The rainbow covenant; challenge: keep one promise you've made

**T1 W4 — The Promise-Maker** · Gen 12:1–9; 15:1–6; 18:1–15; 21:1–7 · Verse: Gen 15:6
*Big idea:* God makes promises and keeps them, even the impossible ones.
- Mon 🎭 "Go!" — Abram leaves home (Abram, Sarai, Lot, servant, God's voice)
- Tue — Count the stars (Gen 15); "he believed the LORD"
- Wed 🎭 Three visitors and Sarah's laugh (Gen 18)
- Thu — Isaac is born (21:1–7); waiting well; challenge: name one thing you're waiting on God for

**T1 W5 — God Is in Control** · Gen 37; 39–41; 45; 50:15–21 · Verse: Gen 50:20
*Big idea:* People may mean harm, but God is working for good and is with us in the pit.
- Mon 🎭 Dreams and the coat (37) — Joseph, brothers, Jacob, traders
- Tue — Slave and prisoner; "the LORD was with Joseph" (39–40)
- Wed 🎭 Pharaoh's dream and Joseph's rise (41)
- Thu — Brothers reunited; forgiveness (45; 50); challenge: forgive/let go of one thing

**T1 W6 — The God Who Rescues** · Ex 1:22–2:10; 3–4; 5–12; 14 · Verse: Ex 15:2
*Big idea:* God hears his people's cries and rescues them — and the Passover lamb points to Jesus.
- Mon 🎭 Baby in the basket — Miriam, Jochebed, princess, servant (2:1–10)
- Tue — Burning bush; Moses' excuses (3–4)
- Wed 🎭 "Let my people go" — Moses, Aaron, Pharaoh, magicians (5–10, selected)
- Thu — Passover and the sea (12–14). *Two-part story: keep it tight; Passover lamb → Jesus is the hinge.*

**T1 W7 — God Lives with His People** · Ex 16:1–21; 17:1–7; 19–20; 25:8–9; 40:34–38 · Verse: Ex 20:2–3
*Big idea:* God provides, gives good rules for living, and moves in to live among his people.
- Mon 🎭 Manna and quail — grumbling, daily bread (16)
- Tue — Water from the rock (17:1–7)
- Wed 🎭 Mountain meeting and the Ten Words (19–20)
- Thu — The tabernacle and God's glory-cloud moving in (40:34–38); "God with us" → Jesus

**T1 W8 — The Shepherd-King** · 1 Sam 16:1–13; 17; Ps 23 · Verse: Ps 23:1
*Big idea:* God looks at the heart; he is the good shepherd who protects and leads.
- Mon 🎭 Samuel looks for a king — Samuel, Jesse, seven sons, David (16)
- Tue — David the shepherd; Psalm 23 line by line
- Wed 🎭 David and Goliath (17) — Goliath handled as a booming silhouette voice, no gore
- Thu — "The LORD rescues" and the greater Shepherd-King to come (John 10:11)

**T1 W9 — Promises Spoken Long Ago** · Isa 9:2–7; 53:1–6 (gentle); Mic 5:2; Jer 31:31–34; Matt 2:1–12 · Verse: Isa 9:6
*Big idea:* Hundreds of years before, God's messengers promised a King and Saviour — and God never forgot.
- Mon 🎭 A prophet in the marketplace — Isaiah's promise "a child is born" (dramatisation labelled)
- Tue — The servant who carries our wrongs (Isa 53, age-appropriate); the silent 400 years
- Wed 🎭 Wise visitors ask directions — Magi, Herod's scribes read Micah 5:2 (Matt 2)
- Thu — A new covenant (Jer 31); "Who is this promise about?"

**T1 W10 — God Keeps His Promise** · Luke 1:26–56; 2:1–38 · Verse: Luke 2:10–11
*Big idea:* Jesus is the promised Saviour — God himself coming to be with us.
- Mon 🎭 Gabriel visits Mary (1:26–38) — Gabriel, Mary, Narrator
- Tue — Mary visits Elizabeth; the song of praise (1:39–56); Zechariah's silence ends (brief)
- Wed 🎭 Bethlehem — innkeeper, Joseph, Mary, shepherds, angels (2:1–20)
- Thu — Simeon and Anna (2:25–38); term recap "Who is God?"; challenge: tell one person one thing about God

### TERM 3 — Having Faith in God *(Jesus' famous parables)* · cycle A2
**Weekly rhythm (consistent so students know what's coming):**
Mon 🎭 *The parable acted* → Tue *Why did Jesus tell it? Who's who? The twist* → Wed 🎭 *Today's retelling* (a modern NZ setting — school, sport, whānau — scripted) → Thu *What does it show about God and the kingdom? Live it.*
Parables are explained as "earthly stories with heavenly meaning." Each Tuesday names the **original audience** and the **surprise** that would have shocked them.

**T3 W1 — The Sower** · Matt 13:1–23 (Mark 4; Luke 8) · Verse: Luke 8:15
*Big idea:* God's word grows in a heart that listens and keeps hold of it. (Includes "What's a parable and why does Jesus use them?")

**T3 W2 — The Good Samaritan** · Luke 10:25–37 · Verse: Luke 10:27
*Big idea:* Loving our neighbour means showing mercy to anyone in need — including people we'd rather avoid.

**T3 W3 — Lost Sheep & Lost Coin** · Luke 15:1–10 · Verse: Luke 15:7
*Big idea:* God searches for the lost and throws a party when one is found.

**T3 W4 — The Lost Son** · Luke 15:11–32 · Verse: Luke 15:24
*Big idea:* The Father runs to welcome us home — and both sons needed his grace.

**T3 W5 — Two Builders** · Matt 7:24–29 (Luke 6:46–49) · Verse: Matt 7:24
*Big idea:* Hearing Jesus's words and doing them is building on rock.

**T3 W6 — The Servant Who Wouldn't Forgive** · Matt 18:21–35 · Verse: Luke 6:36
*Big idea:* We've been forgiven an enormous debt, so we forgive others.

**T3 W7 — The Three Servants (Talents)** · Matt 25:14–30 · Verse: Matt 25:21
*Big idea:* God trusts us with gifts and wants us to use them for him — out of trust, not fear.

**T3 W8 — The Ten Bridesmaids** · Matt 25:1–13 · Verse: Matt 25:13
*Big idea:* Be ready for Jesus's return — real readiness can't be borrowed.

**T3 W9 — The Kingdom Is Worth Everything** · Matt 13:31–33, 44–46 (mustard seed, yeast, treasure, pearl) · Verse: Matt 13:44
*Big idea:* God's kingdom starts small, grows big, and is worth more than anything.
*(Mon 🎭 mustard seed + yeast, Tue the treasure, Wed 🎭 the pearl merchant, Thu compare all four.)*

**T3 W10 — Two Men Who Prayed** · Luke 18:9–14 (with 18:1–8 as a bridge) · Verse: Luke 18:14
*Big idea:* God welcomes the humble who ask for mercy, not those who trust in themselves. Thursday = term recap of all ten parables ("Who told it? What did it show about God?").

> **Easy swaps if you prefer:** Rich Fool (Luke 12:13–21), Great Banquet (Luke 14:15–24), Workers in the Vineyard (Matt 20:1–16), Sheep & Goats (Matt 25:31–46), Persistent Widow (Luke 18:1–8). Per-day outlines for T3 are written out in full when the term is built, following the weekly rhythm above.

## 5. Anatomy of a day

Every day is a slideshow of **12–16 slides** with a minutes budget per slide. **Core slides total 15–18 min. Optional "stretch" slides add up to 2 more (max 20).** The validator enforces this.

### 5.1 Day templates

**Monday 🎭 — "Open the story"** (target 18 min)
| # | Slide | Min |
|---|---|---|
| 1 | Title splash (week + day, animated) | 0.5 |
| 2 | Check-in on last week's challenge *(Week 2+; ties to last week's Bible passage)* + Hook question tied to **today's** passage | 1.5 |
| 3 | Scripture slide (read the key verses) | 1 |
| 4 | Story part 1 — 3–5 narrated beats with art | 4 |
| 5 | Searching question #1 (Look/Think) | 1.5 |
| 6 | **Role-play** — cast + performance | 5 |
| 7 | Debrief question(s) after the script | 1.5 |
| 8 | Directed prayer | 3 |
| – | *Optional:* memory-verse peek, comic-page reveal | +1–2 |

**Tuesday — "Dig in"** (target 18 min)
Recap 1 → Scripture 1 → Story/background 4 → Bible dig (look-closer / word / map / "what did you notice?") 2 → Searching questions ×2–3 (4) → Application (Head–Heart–Hands, first pass) 2 → Memory verse activity 1 → Prayer 3 **= 18.**

**Wednesday 🎭 — "Live the story"** (target 18 min)
Recap/hook 1.5 → Story part 2 with art 3 → **Role-play** 5 → Debrief 1.5 → Searching question (Dig) 2 → Application 1.5 → Memory verse 0.5 → Prayer 3 **= 18.**

**Thursday — "Take it home"** (target 18 min)
Review game (retell the week) 3 → Story wrap-up + the Big Idea reveal 3 → Searching questions ×2 (3) → **This Week's Challenge** (Head–Heart–Hands) 3 → Memory-verse recital 2 → Prayer 3 → Take-home card 1.

### 5.2 Pacing rules
- Teacher speaks ≈ 130–150 words/minute. A 4-minute narrated section = ~520–600 words of `narration`, **not more**.
- Each slide has `minutes` (suggested). The stage shows a quiet pacing bar: green on time, amber when over.
- At least **one `optional: true` slide** per day and at least **one `skippable` slide** (flagged "if you're short on time, skip this") so the teacher can flex between 15 and 20.
- A "short on time" button on the grid view (key `G`) auto-skips all `skippable` slides.

## 6. Content quality rules (apply to every lesson)

1. **Every slide connects to that day's Bible content.** No free-floating games or icebreakers. (Carried over from the old project — keep it.)
2. **Tell the story, don't summarise it.** Narration is vivid, concrete, sensory, and accurate to the text. Fill-in details are only what the text plausibly implies and never contradict it. Where a detail is imagined, the teacher note says so.
3. **Searching questions** (≥ 3 per day) follow the four-level ladder and every day has at least one at each of the first three levels, plus the application level somewhere:
   - **Look** — what does the text actually say? (observe)
   - **Think** — why did it happen / what does it show about God? (interpret)
   - **Dig** — the hard or deeper question: motive, tension, "what would you have done?", "where else in the Bible…?"
   - **Live** — so what? (apply to my life, this week)
   Each question has: `level`, `mode` (see §9), `text`, `hint` (teacher-only: expected answers, 2 follow-ups, "if there's silence, try…").
4. **Application is concrete.** Never "be kinder". Always a specific, doable action in a named setting (home / playground / group chat / sport / sibling), tied to the passage.
5. **Gospel-centred, not moralistic.** Each week must show *what this teaches about God* and how it points to Jesus (where natural — never forced). The "Big Idea" is a single sentence a student can repeat.
6. **Age-appropriate honesty.** Sin, death, and suffering are named plainly and never graphically. Always land in God's character and hope.
7. **NZ English** (colour, favourite, whānau where natural). Te reo Māori used correctly with macrons and never as decoration.
8. **Inclusive of non-churched children.** Brief jargon explanation the first time any churchy word appears in a week ("covenant = a serious promise agreement").
9. **Accuracy gates.** Anything historical (Term 4 Weeks 8–10) is verified by web search at build time, with sources noted in the teacher notes. If a fact can't be confirmed, it's left out or labelled "tradition says".
10. **Variety inside the routine.** Same skeleton (kids love predictability) but vary the *mode*: stand/sit votes, think-pair-share, write-on-mini-whiteboard, silent think, "freeze-frame" in role-plays, "spot it in the text", "finish this sentence".
11. **Monday ↔ Thursday loop.** Thursday sets the week's challenge; next Monday's check-in asks how it went. The check-in's wording must name last week's story ("Last week we met Noah… did you…").

## 8. Role-play spec (every Monday & Wednesday = 80 scripts)

**Upgrade of the current presenter:** same fullscreen, one-line-at-a-time, giant text, arrows/space/tap, per-character colour badge — plus:

1. **Intro card** (before starting): title, passage, "based on [ref]; some words imagined", character list with one-line descriptions, **suggested actions** ("Everyone: make wind sound"), optional props.
2. **Cast picker:** "Pick volunteers" spins through the saved class list and assigns roles (reroll per role, "skip absent student"). Falls back to "Raise your hand" when no list is saved.
3. **Script format**
   ```js
   { type:"roleplay", title:"The Serpent's Question", ref:"Genesis 3:1–7",
     imagined:"Tone and small gestures are imagined; the words of Genesis 3 are kept close.",
     characters:[ {name:"Narrator",color:"#F2C77B"}, {name:"Serpent"}, {name:"Eve"}, {name:"Adam"}, {name:"Everyone"} ],
     props:["Optional: a piece of fruit"],
     lines:[
       { character:"Narrator", text:"…", direction:true },                        // stage direction (italic, no badge)
       { character:"Serpent", text:"Did God really say…?", action:"sneaky whisper" },
       { character:"Everyone", text:"Ssssssss!", sfx:"hiss" },                    // crowd line for the rest of the class
       { pause:"Freeze! What would you do if you were Eve right now?", seconds:20 }, // freeze-frame question
       …
     ],
     debrief:[ {level:"think", text:"…", hint:"…"} ] }
   ```
4. **Length:** 18–35 lines, **3–6 speaking roles + Narrator + an "Everyone/Crowd" role** so the whole class can join. Performance time ≈ 4–5 min; with casting ≈ 5–6 min.
5. **At least one `pause` (freeze-frame) per script** to turn watching into thinking.
6. **Reading level:** short lines (≤ 25 words), strong verbs, humour where the text allows, reverent where it demands. Parable retellings (T3 Wednesdays) are set in modern NZ settings.
7. **God's speech:** in Scripture-direct lines use the text verbatim; show God's lines in a distinct "voice of God" style (gold glow, no avatar).
8. **Debrief (1.5–2 min):** after the last line, 1–2 questions appear automatically ("What did you notice about God in that scene?").
9. **Sensitive scripts** (Isaac, flood, Stephen, Polycarp): death/violence implied, never shown; the script card carries a teacher note on handling.
10. **Persistence:** `←/→/Space/click`, swipe on touch, `Esc` to exit, `B` to blackout, and the script resumes where it stopped if closed accidentally.

## 9. Searching questions & application spec

### 9.1 Question modes (vary them)
`pair` (think-pair-share with timer) · `silent` (think 20s, then share) · `write` (mini-whiteboard) · `vote` (stand/sit, thumbs, move to a side of the room) · `discuss` (whole class) · `poll` (A/B/C options with a reveal) · `finish` (complete this sentence).
Every question slide has a visible **thinking-timer ring**, and a teacher-only hint panel with: *what a good answer sounds like*, *two follow-up questions*, *what to say if there's silence*.

### 9.2 Question quality bar
- Not answerable yes/no; not answerable without the passage.
- At least one per day invites disagreement or tension ("Was it fair…?" "What would you have done?").
- Application questions name a real setting.

### 9.3 Application = Head → Heart → Hands
- **Head:** "What did we learn about God today?" (one sentence the student can say)
- **Heart:** "What does this make you want to say to God / what do you need to change or trust him with?"
- **Hands:** "One thing I'll do this week" — concrete, small, time-bound, with a named setting.
Thursday's `challenge` slide pulls the week's Hands into a **take-home card** (printable and shown on screen). Next Monday's `hook.checkin` follows up.

## 10. Directed prayer spec (every day)

**Goal:** by the end of the year every student can pray in their own words and knows several ways to do it.

### 10.1 The framework — "Wow · Sorry · Thanks · Please"
1. **Wow** — praise God for who he is (linked to today's passage: "Wow, God, you are…")
2. **Sorry** — honesty and forgiveness ("God, I'm sorry for…")
3. **Thanks** — gratitude ("Thank you for…")
4. **Please** — asking for yourself and others ("Please help…")

### 10.2 Structure of the `prayer` slide
```js
{ type:"prayer", id:"m-pray", minutes:3, mood:"calm",
  tip:"You can't pray it wrong — God is a loving Father who loves to hear from you.",   // one new "how to pray" tip per day
  opening:"Let's get comfortable. Close your eyes or look at the floor… Take a slow breath.",
  phases:[
    { name:"Wow",    lead:"Think about what we heard about God today…", prompts:["God, you are powerful because…","God, you are …"], starter:"Wow, God, you are…",  seconds:35 },
    { name:"Sorry",  lead:"…", prompts:["…","…"], starter:"God, I'm sorry for…", seconds:30 },
    { name:"Thanks", lead:"…", prompts:["…","…"], starter:"Thank you, God, for…", seconds:35 },
    { name:"Please", lead:"…", prompts:["…","…"], starter:"Please, God, help…",  seconds:40 }
  ],
  style:"silent",          // silent | out-loud | pairs | write | hands | stand | psalm
  closing:"Let's finish together. Everyone: Amen.",
  notes:"Teacher: model a one-sentence prayer first. Reassure that short and simple is great." }
```
- Each phase shows its name big, 2–3 **prompts tied to that day's passage** (never generic), the **sentence starter**, and a soft silence ring (`seconds`). Teacher advances manually; the ring is a guide.
- Teacher may click **"Pray it aloud as a class"** to show a short repeat-after-me line.
- **Variety of `style`** across the week so students learn different ways: silent, one-sentence out loud, pairs (praying for each other), writing a prayer, kneeling/hands open, a psalm prayed line by line.

### 10.3 Prayer-skill ladder (taught by design)
| Term | Skill focus |
|---|---|
| **T1** | **W1** Wow · **W2** Sorry · **W3** Thanks · **W4** Please · **W5** all four in order · **W6** praying for others by name · **W7** thanking for daily needs (manna) · **W8** praying a psalm (Ps 23) · **W9** praying God's promises back to him · **W10** Mary's song as a model of praise |
| **T2** | Praying with trust: praying Scripture back (W1–2) · praying when you feel small (W3) · praying and waiting (W4) · persistent prayer (W5) · prayer when you disagree with how things are going — "even if" prayers (W6) · praying for your place/role (W7) · praying for friends by name (W8) · praying when afraid (W9) · "Lord, help my unbelief" (W10) |
| **T3** | **The Lord's Prayer, one phrase a week** — W1 "Our Father" · W2 "Hallowed be your name" · W3 "Your kingdom come" · W4 "Your will be done" · W5 "Give us today our daily bread" · W6 "Forgive us… as we forgive" · W7 "Lead us… deliver us" · W8 "For yours is the kingdom…" · W9 whole prayer in your own words · W10 humble prayer: the tax collector's prayer |
| **T4** | Praying like the early church: boldness (W1) · praying for enemies/those who hurt us (W2) · praying for friends who don't know Jesus (W3) · praying for guidance (W4) · praying with joy in trouble (W5) · praying for team-mates (W6) · praying in a storm (W7) · praying for the persecuted church (W8) · praying for Bible-hunger (W9) · writing a daily-prayer plan; students' own prayer (W10) |

## 13. Image system (ChatGPT-generated art)

### 13.1 Style bible — derived from the reference comic page
What makes the reference work, and what every image must reproduce:
- **Black-and-white manga / graphic-novel ink art**; bold confident outlines; large areas of **solid-black silhouette**.
- **Soft grey airbrushed gradients** for sky and mist, fine halftone/tonal shading.
- **Cinematic camera**: wide establishing shots with simple architecture lines, low-angle ranks of figures, dramatic close-ups (a child's wide eyes), light rays and speed lines.
- **Ancient Middle-Eastern setting**: mud-brick and stone buildings, flat roofs, robes, turbans/head cloths, spears, sandals.
- **Danger by implication**: shadows, silhouettes, torchlight — never blood or injury.
- Comic **caption boxes** (white, black border) and chunky outlined title lettering are added **by the app in HTML**, *not* baked into the images (AI text rendering is unreliable).

### 13.2 MASTER STYLE BLOCK (pasted at the top of every prompt)
```
STYLE: Black-and-white manga / graphic-novel illustration in bold ink. Thick confident black outlines, dramatic high-contrast lighting, large solid-black silhouettes, soft grey airbrushed gradient skies, fine halftone shading, dynamic light rays and speed lines. Cinematic camera angles (low-angle, wide establishing shot, dramatic close-up). Ancient Middle-Eastern first-century world: mud-brick and stone buildings with flat roofs, robes, head cloths, sandals, olive trees, desert hills. STRICTLY MONOCHROME — black, white and greys only, no colour. Hand-inked look; not photorealistic, not 3D, not painterly, not cartoonish-cute. Child-appropriate: no blood, gore or graphic violence — danger is shown through silhouettes, shadows and expressions. ABSOLUTELY NO TEXT: no letters, words, captions, speech bubbles, signatures or watermarks anywhere in the image. Keep the main subject clear and leave a calmer area of sky or ground in the top or bottom third.
```

### 13.3 Prompt template (what `export-prompts.js` writes for every image)
```
[MASTER STYLE BLOCK]

FORMAT: {landscape 3:2 (1536×1024) | portrait 2:3 (1024×1536) | square 1:1}
SHOT: {wide establishing | medium | close-up | low-angle | silhouette | over-the-shoulder}
SCENE: {1–3 sentences: who, where, doing what, light, mood}
CHARACTERS: {names → locked descriptors from the Character Bible; "match the attached reference sheet"}
COMPOSITION NOTES: {focal point; where to leave space for captions}
```

### 13.4 Character Bible (`data/characters.js` → `images/characters/`)
Generate **one reference sheet per recurring character first** (front, 3/4, side, a close-up of the face, one expression sheet), then attach the sheet to every later prompt featuring them with *"Keep this character exactly as in the attached reference sheet."* Locked descriptors, e.g.:
- **Jesus** — man in his early 30s, shoulder-length dark wavy hair, short dark beard, plain undyed tunic and cloak, kind strong face; shown reverently, often from behind / in silhouette / in a wide shot. *(God the Father: never a figure — light, rays, clouds only.)*
- **Moses, Abraham, Joseph, David, Peter, Paul, Mary, Esther, Daniel, Gideon, Hannah, Elijah…** — one line each with age, hair, build, garment, signature item (staff, shepherd's sling, shawl, scroll).
- **Recurring crowd types** — shepherds, soldiers (helmets, silhouettes), villagers, children.
Consistency tips: one ChatGPT chat **per week**; paste the style block once at the top of the chat and say "use this style for every image I ask for"; re-attach reference sheets each time; ask for "same character, same costume".

The app is designed to look good with **zero** images (§13.7), so art can arrive gradually — generate Term 1 while Term 2 is being written.

### 13.6 Files, names, and workflow
- **Landscape art:** `images/tN/wNN/tNwNNdD-a.webp` and `-b.webp` (e.g. `images/t1/w01/t1w01d1-a.webp`). **Covers:** `tNwNN-cover.webp`. **Comic pages:** `tNwNN-comic.webp`. **Shared:** `images/shared/…`.
- ChatGPT outputs PNG at 1536×1024 / 1024×1536. Drop them into a working folder, rename to the key shown in the prompt file, run `python tools/optimize-images.py` → WebP, max 1600 px wide, ~150–300 KB each, copied into the right folder.
- `tools/export-prompts.js` produces `IMAGE_PROMPTS_T1.md` … `T4.md`, **one section per week, ready to paste**: each entry shows `key`, target filename, format, where it appears ("Mon · story beat 2"), and the full prompt (style block included). Because prompts live next to the slide that uses them, art and story can never drift apart.

### 13.7 Placeholder rule (never a broken slide)
If an image file is missing, the slide renders a **designed placeholder**: mood-coloured ink-wash gradient, halftone dots, animated light rays, and a small corner tag `art: t1w01d1-a`. Teacher view shows the tag; student view just sees a stylish backdrop. The loader tries `.webp` then `.jpg` then `.png`.

### 13.8 Safety & reverence rules for every prompt
No gore, no blood, no weapons being used on a person (weapons may be held/raised in silhouette); death and suffering implied only. God the Father never depicted. No real-person likenesses of living people; historical figures (Polycarp, Tyndale, Marsden, Ruatara) drawn as respectful illustrated characters, not portraits. No copyrighted characters/styles by name. Māori figures drawn with dignity and accuracy — no caricature; ask the teacher to review Term 4 Week 10 art.

## 14. Validation & tooling (`node tools/validate.js`)

The validator is mandatory after every batch and prints a coverage table. **A week is "built" only if it passes everything below.**

**Structure** — each term has exactly `Week 1…Week 10`; each week has exactly 4 days labelled Monday–Thursday; required week fields present (`lessonTitle, passage, bigIdea, memoryVerse, prayerFocus, cover`); every day has `learningIntentions` (3), `assessment`, `resources`, `whereToNext`.

**Timing** — core slides (`optional:false`) sum to **15.0–18.5 min**; core + optional ≤ **20.0**; every slide has `minutes`; at least one `optional` and one `skippable` slide per day.

**Roleplay** — `roleplay:true` ⇔ a `roleplay` slide exists on **Monday and Wednesday**, none on Tue/Thu; each script has 18–35 lines, ≥ 3 speaking characters, an `Everyone` role, ≥ 1 `pause`, a `debrief`, and an `imagined` note.

**Questions** — ≥ 3 `question` slides per day; levels cover `look`/`think` and `dig`; every question has a `hint` (≥ 25 words); the day includes `apply` or `challenge` content.

**Prayer** — exactly one `prayer` slide per day; 4 phases (Wow/Sorry/Thanks/Please) each with ≥ 2 prompts + a starter; `tip` present; `style` present; prompts are not on a banned-generic list.

**Story / content** — each day has a `scripture` slide with `ref`; Monday–Wednesday story narration word counts are within the 130–150 wpm × minutes bound; no `TODO`/`TBC`/`lorem`; no `</script>`; NZ spelling check on a small word list (color→colour, favorite→favourite, etc.); every Thursday has a `challenge`; every Monday from Week 2 has a `hook.checkin`.

**Art** — every `art.key` is unique, follows the naming convention, and has a `prompt` ≥ 20 words; report missing image files (warning only). `export-prompts.js` fails if any prompt lacks the style block or contains the words "text", "caption" or "speech bubble" as *content* requests.

**Output** — `BUILD_STATUS.md` regenerated: per-term/week/day ✅/⚠️/❌, total minutes, role-play count, prompt count, image-file coverage %.
