1. **Make the character sheets first** (Section A) — one ChatGPT chat each. Save them; you'll attach them later.
2. **Start one new ChatGPT chat for the week.** Attach the character sheets for this week (Peter, John).
3. **Paste one prompt at a time.** Every prompt is complete — the style instructions are already inside it.
4. If colour or text creeps in, reply: *"Redo it strictly black-and-white, with no text anywhere."*
5. **Save each image with the exact name shown** (e.g. `t1w01d1-a.png`) into the folder shown. The app finds it automatically — `.png`, `.jpg` or `.webp` all work — and the "Image to come" box disappears.
6. God the Father is never drawn as a person — only light. If a face appears for God, regenerate.
