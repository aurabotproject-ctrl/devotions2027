# Morninglight 2027 — Image Prompts: TERM 4

**Trusting and Following Jesus (Acts → Aotearoa) · 10 weeks · 100 cover/scene/comic images + 18 character sheets + 2 term backdrops**

Generated from the finished Term 4 lesson data by `node tools/export-term-prompts.js 4`, so every key and scene matches the slides exactly. (The per-week files `IMAGE_PROMPTS_T4_WEEKn.md` contain the same prompts, one week at a time, with where each image is used.)

Every prompt below is **complete and self-contained** — the full style instructions are already inside each one. Open the code box, click copy, paste into ChatGPT. Nothing else needs adding.

## How to use this file

1. **Do the character sheets first** (Section A). Generate each one, save it, and keep it handy. Sheets you made in earlier terms are reused — they're not repeated here.
2. **One ChatGPT chat per week.** At the start of a week's chat, attach the sheets listed under that week's heading. The scene prompts already tell ChatGPT to match an attached sheet.
3. **Paste prompts one at a time.** If ChatGPT drifts in style (colour creeping in, text appearing), reply: *"Redo it strictly black-and-white with no text anywhere."*
4. **Save each image with the filename shown** (e.g. `t4w01d1-a`) and put it in `images/t4/wNN/` (characters in `images/characters/`, backdrops in `images/shared/`) — or just send them to me in order and I'll add them.
5. **Landscape images** are 3:2 and cropped to 16:9 on screen. Comic pages are portrait and are for the comic-page viewer coming in a later build.
6. **Reverence reminder:** God the Father is never drawn as a figure — only light. Jesus is drawn reverently (wide shots, from behind or three-quarter).
